How I work

Short loops from a user problem to a working screen and a measured result.

01

AI-native

About 78% of my working time goes through AI tools. Claude Code is connected directly to our databases and APIs: I pull data, run analysis, cluster user feedback and draft specs myself. Python and R for my own data work.

02

Prototypes on GitHub

I build clickable HTML prototypes with AI and publish them on GitHub Pages. The team discusses a working screen on a phone, not a document, and changes are highlighted right on the prototype.

03

With designers

I bring the problem, the content and the prototype; the designer owns the final solution. Triads of product, design and engineering keep the loop short.

04

Hypotheses and experiments

JTBD interviews and competitor journeys feed the backlog. Every hypothesis is scored before work starts and checked after launch: plan versus fact, on web and in the app.

Analytics: Amplitude, Metabase, SQL, GA4, Tableau, Looker Studio, Google Sheets.
